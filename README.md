# LeadMap

Личный рабочий инструмент для сбора открытых карточек организаций из Яндекс Карт. Он помогает найти компании по городу и категории, проверить наличие сайта, сохранить результат в CSV и вести дальнейшую обработку лидов без ручного копирования каждой карточки.

В репозитории две связанные части:

- `maps_parser` — Playwright-парсер, CLI и Telegram-интерфейс;
- `web` — отдельная LeadCRM на FastAPI, PostgreSQL и React.

Это не универсальный SaaS и не средство обхода ограничений площадки. Селекторы Яндекс Карт могут меняться, поэтому перед рабочим запуском результат нужно проверять на небольшой выборке.

## Что умеет парсер

- собирать название, рубрики, адрес, контакты, рейтинг и ссылку на карточку;
- различать подтверждённое отсутствие сайта и неопределённый результат;
- вести реестр уже обработанных организаций и не создавать дубли;
- формировать CSV/XLSX и текстовые подборки для менеджера;
- по желанию готовить черновики сообщений через DeepSeek;
- запускать те же сценарии из Telegram с ограничением по разрешённым chat ID;
- сохранять незавершённую задачу при капче и продолжать её позднее.

## Ограничения и безопасное использование

Парсер останавливается при защитной проверке и не пытается её обходить. Используйте только те данные и сценарии, которые разрешены правилами источника и применимым законодательством. Автоматическая отправка писем выключена по умолчанию: команда отправки требует отдельного флага и явного подтверждения.

Секреты хранятся только в локальном `.env`. Не публикуйте API-ключи, токены Telegram и SMTP-пароли. Для Telegram обязательно заполните `TELEGRAM_ALLOWED_CHAT_IDS`, если бот доступен из интернета.

## Установка

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env
```

В PowerShell активация окружения и копирование файла выглядят так:

```powershell
.\.venv\Scripts\Activate.ps1
Copy-Item .env.example .env
```

DeepSeek, Telegram и SMTP нужны только для соответствующих дополнительных функций. Для обычного `scrape` достаточно настроек парсера.

## Запуск

Собрать карточки без генерации текстов:

```bash
python run.py scrape --query "кофейни" --location "Волгоград" --limit 20
```

Запустить полный локальный пайплайн:

```bash
python run.py run --query "кофейни" --location "Волгоград" --limit 20
```

Результаты сохраняются в `out/`. Для повторных запусков там же ведутся реестры уже обработанных карточек.

Сгенерировать черновики по готовому CSV:

```bash
python run.py generate --input out/leads_20260905_120000.csv
```

Запустить Telegram-интерфейс:

```bash
python run.py bot
```

Отправка email вынесена в отдельную команду и требует осознанного подтверждения:

```bash
python run.py send \
  --input out/messages_20260905_120000.jsonl \
  --send-emails \
  --confirm-send I_UNDERSTAND_THIS_SENDS_EMAIL
```

Перед отправкой проверьте адресатов, текст и наличие понятного способа отказаться от дальнейших сообщений.

## Профили скорости

Переменная `PARSER_PROFILE` принимает `safe`, `normal`, `fast` или `long`. По умолчанию используется `normal`. Быстрый профиль уменьшает паузы, но повышает вероятность защитной проверки; для длительных задач лучше начинать с `safe` или `normal`.

```bash
python -m pytest -q tests

```
