# Maps Parser

CLI-пайплайн для поиска организаций в Яндекс Картах, фильтрации заведений без сайта, генерации персонального сообщения через DeepSeek и подготовки черновиков для контактов.

## Важно про ключи и отправку

Не храните API-ключи в коде. Ключ DeepSeek, который уже был отправлен в чат, лучше перевыпустить в личном кабинете и положить новый в `.env`.

Telegram-токен тоже лучше перевыпустить у BotFather, если он попадал в чат или логи. В код он не вшивается: бот читает `TELEGRAM_BOT_TOKEN` из `.env`.

Автоматическая отправка писем по умолчанию выключена. Скрипт сначала создает черновики в `out/messages_*.jsonl`. Реальная отправка включается только отдельным флагом и явным подтверждением.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install chromium
Copy-Item .env.example .env
```

Затем заполните `.env`.

## Быстрый запуск

```powershell
python run.py run --query "кофейни" --location "Волгоград" --limit 20
```

Что произойдет:

1. Скрипт откроет Яндекс Карты через Playwright.
2. Соберет карточки организаций по запросу.
3. Оставит только те, у которых не найден сайт.
4. Отправит данные в DeepSeek.
5. Сохранит лиды и тексты в `out/`.

## Telegram-бот

Добавьте в `.env`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_ALLOWED_CHAT_IDS=
TELEGRAM_DEFAULT_LIMIT=10
```

Запуск:

```powershell
python run.py bot
```

Команды в Telegram:

```text
/city Волгоград
/limit 20
/manager Иван
/contacts phone
/leadstatus 3 contacted Договорились созвониться завтра
/resume
/status
```

Поиск запускается кнопкой в меню. Режим `Список без сайта` формирует единый список
по всем выбранным категориям. Лимит `20` означает максимум 20 итоговых организаций,
а не 20 для каждой категории.

Фильтры контактов:

- `phone` — только организации с телефоном;
- `any` — телефон, email или мессенджер;
- `all` — включая организации без найденных контактов.

Бот отправляет копируемые сообщения группами до 10 организаций, CSV и XLSX.
Лимит в режиме «Список без сайта» теперь считается как цель по подтверждённым
организациям без сайта: если выбрано 20, бот продолжает проверять карточки, пока
не наберёт 20 подходящих организаций, пока не закончится выдача Яндекс.Карт или
не будет достигнут защитный максимум `NO_SITE_SCAN_MAX_CARDS`.

Одновременно обновляется `out/crm_leads.csv`. Для каждой строки сохраняются менеджер,
статус, комментарий и даты работы. Статусы: `new`, `assigned`, `contacted`,
`declined`, `interested`, `followup`.

Если Яндекс показывает капчу, бот сохраняет недостающую часть задачи и автоматически
пробует продолжить через 15 минут. `/resume` запускает сохраненное продолжение вручную.

## Проверка сайта и бережный режим

Вердикт по сайту стал строже:

- `present` — найден внешний сайт организации;
- `absent` — сайт не найден после нескольких проверок DOM/HTML и раскрытия контактов;
- `unknown` — есть признаки сайта/редиректа, но итоговый адрес не подтвердился. Такие
  организации не попадают в список «без сайта».

По умолчанию включены более длинные паузы между карточками, случайный jitter и
периодический cooldown после серии карточек. Это снижает нагрузку на Яндекс.Карты и
останавливает сбор при капче, но не пытается обходить защиту площадки.

Для ограничения доступа укажите свой chat id в `TELEGRAM_ALLOWED_CHAT_IDS`, например `123456789` или несколько через запятую.

```powershell

```

## Генерация по готовому CSV

CSV может содержать колонки `name`, `categories`, `address`, `phone`, `email`, `website`, `rating`, `reviews`, `hours`, `yandex_url`.

```powershell
python run.py generate --input out/leads_20260510_120000.csv
```

## Отправка email

Скрипт отправляет только на email-адреса, найденные в данных. Телефоны остаются как контакты для ручной обработки.

```powershell
python run.py send --input out/messages_20260510_120000.jsonl --send-emails --confirm-send I_UNDERSTAND_THIS_SENDS_EMAIL
```

Перед отправкой проверьте, что тексты корректны, письма соответствуют правилам площадок и законам о рекламе/персональных данных, а в письме есть понятный способ отказаться от дальнейших сообщений.
